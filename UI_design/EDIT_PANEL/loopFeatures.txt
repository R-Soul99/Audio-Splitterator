Loop memory presets and grouped Loop / Sample Controls
Implementation status: 8 October 2026; awaiting Leroy's interactive review.
Branch: feat/loop-memory-presets, based on current main 910009d.

This status replaces the earlier proposed bottom-row 1-10 layout. The current
brief specifies three bordered sections and the 7-8-9 / 4-5-6 / 1-2-3 / wide 0 keypad.

Implemented
- Boundaries: stacked Start, End, Length with half / double beside Length.
- Loop Tools: 1st Beat readout; Set / Clear / single-arrow Jump; Slide encoder / Save.
- Start Beat renamed to 1st Beat in visible text, marker labels and accessible names.
- Three-decimal seconds readouts, dim internal s suffix, snug stable widths.
  Focus / Enter / blur without edits preserves exact samples; entry / Escape and
  coarse / Shift fine arrows retain established behavior.
- Slide arrow buttons removed. Encoder preserves viewport-scaled movement,
  Shift fine movement, exact boundary clamping and immediate reversal.
- Ten recording-owned session slots; 0 is the tenth slot.
- Empty click stores exact Start, End, 1st Beat and custom-marker state.
  Filled click recalls; Shift-click replaces with a valid current loop;
  right-click / focused Delete clears without stopping or clearing the current loop.
- Digits / Num Lock number-pad digits act like ordinary clicks while Edit's
  Loop / Sample Controls is visible. Text entry, modifiers and repeats are ignored.
- Recall restores the existing selection, arms looping and cancels beat placement.
  Playing recalls use the existing non-overlapping source handover at 1st Beat.
  Stopped / paused recalls do not autoplay; next explicit start begins at 1st Beat.
- Presets do not change with edits. Exact matching illuminates the most recently
  stored / recalled matching slot. Empty, filled, active, pressed, Shift and focus
  states are distinct; release / cancel / blur clears transient highlighting.
- Memory survives Tools / Controls / Save / workflow navigation, and clears on
  new import or recording-buffer replacement. No cross-restart persistence.
- Fixed device, waveform, Tools tabs / Loop On switch and ruler preserved.
  Rotated exports, remembered preferences, overwrite protection and successful
  save return to Controls retain their existing behavior.
